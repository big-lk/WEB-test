# オフライン版 応答の木（offline-tree-v1.0）

各回の回答は、下の「枠」を上から順に埋めて作る。枠に入る文はすべてこの表にある（参加者の語は料理名・項目名などの登録語だけ差し込む）。
応答ごとに、通った節点の ID が meta.offlineTrace.nodes に残る。

## 回ごとの枠
